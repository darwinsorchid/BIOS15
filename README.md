# BIOS15 – Statistics and Modelling in Biology

Course projects and reports for BIOS15, written in R and Quarto.

## Projects

| Folder                                     | Description                                                                                                 |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------- |
| [`linear-regression/`](linear-regression/) | Brain–body size allometry in male and female birds, analyzed with linear regression on log-transformed data |

## Reproducing the analyses

Each project folder contains a Quarto document (`.qmd`) and its data. To render a report, open the folder's `.Rproj` file in RStudio and click **Render**.
